
## 📌 Overview

**MVC-CRUD** is a Java-based web application that demonstrates the implementation of the **Model–View–Controller (MVC)** architectural pattern along with basic **CRUD (Create, Read, Update, Delete)** operations.
The project is designed to show how to structure a web application in a clean, maintainable, and scalable way while handling data operations efficiently.

This project is ideal for learning and practicing core backend concepts and is suitable as a foundation for more advanced applications.

---

## 🚀 Features

* Create new records
* Read and display existing records
* Update existing records
* Delete records
* Clear separation of concerns using MVC architecture
* Simple and understandable project structure

---

## 🏗 MVC Architecture

The project follows the **MVC design pattern**, which separates the application into three main components:

### 🔹 Model

* Represents the application data
* Contains business logic
* Interacts with the data source (database or in-memory storage)

### 🔹 View

* Responsible for the user interface
* Displays data to the user
* Typically implemented using JSP/HTML

### 🔹 Controller

* Handles user requests
* Acts as an intermediary between Model and View
* Processes input and returns the appropriate response
